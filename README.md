
# AI Article Generator

## Project Overview
AI Article Generator is a web-based application that automatically generates professional articles based on user-provided topics using an AI-powered automated workflow.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- n8n Automation
- Webhooks
- AI Integration

## Features
- Generate articles based on user topics
- AI-powered article generation
- Automated workflow using n8n
- Copy generated articles
- Download articles as text files
- Responsive user interface

## How It Works
1. User enters an article topic.
2. JavaScript sends a POST request to an n8n webhook.
3. n8n receives and processes the request.
4. The configured AI workflow generates an article.
5. The generated article is displayed on the website.
6. Users can copy or download the article.
